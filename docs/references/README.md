# Visualization references

The [challenge page and video review](challenge/README.md) contains the original
challenge HTML, decoded details/resources, automatic English captions, and
timestamped findings about additional data sources.

See [Dominic Royé: visualization choices](dominic-roye/README.md) for reviewed
examples, source links, and their application to the two-day hackathon.

Local HTML files are source snapshots for reference, not a complete offline
website. Remote fonts, scripts, styles, and some images may require networking.
The `examples/` directory contains selected original example images, when
successfully downloaded, for reference rather than as application assets.
`examples/firefly-map.png` (36 MB) is not committed; fetch it from the URL in
[dominic-roye/sources.json](dominic-roye/sources.json) if needed:

```sh
curl -o docs/references/dominic-roye/examples/firefly-map.png https://dominicroye.github.io/blog/firefly-maps/img/figure-html/unnamed-chunk-11-1.png
```
