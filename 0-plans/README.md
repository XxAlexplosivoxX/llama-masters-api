# 0. Plans

- [Harmonization plan](HARMONIZATION_PLAN.md): MODIS → VIIRS (NOAA-20 scale) conversion,
  cleaning, validation scorecard, outputs. The core of the challenge.
- [Hackathon plan](HACKATHON_PLAN.md): six-person roles, two working days,
  data gate, deliverables, and demo acceptance checks.
- [Forecasting plan](FORECASTING_PLAN.md): seasonal baseline, XGBoost with
  MLForecast, TimeGPT comparison, and evaluation.
- [Visualization plan](VISUALIZATION_PLAN.md): time-boxed globe prototype,
  regional map, calendar, and visual integration.

The hackathon plan governs the two-day scope; broader modeling ideas in the
forecasting plan are optional. Visualization and challenge source material is in
[references/](references/README.md). Data steps are numbered folders, starting with
[1-extract_data/](../1-extract_data/README.md).
